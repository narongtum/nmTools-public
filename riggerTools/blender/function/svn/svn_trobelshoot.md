 นี่คือขั้นตอนการแก้ไขผ่านการจัดการฐานข้อมูล SQLite ของ SVN โดยตรงครับ

### ขั้นตอนการแก้ไข (Step-by-Step)

1. **เตรียม SQLite Tool**:
* ไปที่ [sqlite.org/download.html](https://www.sqlite.org/download.html)
* ดาวน์โหลดไฟล์ **sqlite-tools-win-x64-xxxxxxx.zip**
* แตกไฟล์ (Unzip) แล้วก๊อปปี้ไฟล์ `sqlite3.exe` มาวางไว้ในโฟลเดอร์หลักที่มีปัญหา คือ `D:\svn_repo`


2. **เปิดใช้งาน Command Prompt**:
* กดปุ่ม `Windows + R` พิมพ์ `cmd` แล้วกด `Enter`
* พิมพ์คำสั่งเพื่อเข้าไปยังโฟลเดอร์งานของคุณ:
```cmd
d:
cd \svn_repo

```


3. **ตรวจสอบและลบ Work Queue**:
* โฟลเดอร์ `.svn` จะถูกซ่อนอยู่ (Hidden folder) แต่เราสามารถเข้าถึงได้ผ่าน command
* รันคำสั่งเหล่านี้ทีละบรรทัดเพื่อล้างคิวงานที่ค้างอยู่:
```cmd
sqlite3 .svn/wc.db "delete from work_queue"
sqlite3 .svn/wc.db "delete from wc_lock"

```


* *คำอธิบาย:* คำสั่งแรกจะลบงานที่ติดขัดอยู่ในคิว และคำสั่งที่สองจะปลดล็อกสถานะฐานข้อมูลที่ค้างอยู่


4. **ทำการ Cleanup ผ่าน GUI**:
* กลับไปที่หน้าต่าง Folder Explorer (คลิกขวาที่โฟลเดอร์ `D:\svn_repo`)
* เลือก **TortoiseSVN > Cleanup**
* **สำคัญ:** ในหน้าต่าง Cleanup ให้ติ๊กเลือกช่องดังนี้:
* [x] **Break locks**
* [x] **Fix time-stamps**
* [x] **Vacuum pristine** (ถ้ามีตัวเลือกนี้)


* กด **OK**



---

### หากปัญหายังคงอยู่

หากทำตามขั้นตอนข้างต้นแล้วยังมี Error แจ้งว่า "No checksum is recorded for this file" แสดงว่าไฟล์ในฐานข้อมูล `pristine` ของคุณหายไปจริงๆ วิธีสุดท้ายที่แนะนำคือ:

* **Export งานออกมาใหม่**:
1. สร้างโฟลเดอร์ใหม่ เช่น `D:\svn_repo_backup`
2. ใช้ TortoiseSVN ทำการ **Export** จาก Repository มายังโฟลเดอร์ใหม่นี้ (เพื่อให้ได้ไฟล์ล่าสุดที่ถูกต้อง)
3. ย้ายไฟล์ที่แก้ไขแล้ว (ถ้ามี) จากโฟลเดอร์เก่ามาที่ใหม่
4. ลบโฟลเดอร์เก่า (`D:\svn_repo`) ทิ้งไป


วิธี Export ใหม่เป็นวิธีที่สะอาดที่สุดและลดความเสี่ยงที่ฐานข้อมูลจะเสียหายซ้ำซ้อนครับ
